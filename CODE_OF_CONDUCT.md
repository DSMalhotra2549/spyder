# Code of conduct

Spyder follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good faith, and keep criticism about the work, not the person. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else in the project.

## Reporting

If someone's behaviour in the project is a problem, contact the maintainer privately through their [GitHub profile](https://github.com/perplexingpasta) rather than replying in public. Reports are kept confidential.

The maintainer may edit or remove comments, close issues or pull requests, and block people who don't follow this code, as described in the Contributor Covenant's enforcement guidelines.
